# 📈 Parametric Models using Python

Welcome to my **Parametric Models** repository! 🚀

This repository contains hands-on implementations of **Regression-based Machine Learning algorithms** using **Python** and **Scikit-Learn**. The notebooks demonstrate complete workflows including data preprocessing, model building, evaluation, and prediction on real-world datasets.

---

# 📚 Repository Overview

This repository includes practical implementations of:

### 📊 Linear Regression
- 🔹 Simple Linear Regression
- 🔹 Multiple Linear Regression
- 🔹 Model Training & Prediction

### 🚗 Regression Projects
- 🔹 Cars Mileage Prediction
- 🔹 Claimants Prediction

### 📏 Model Evaluation
- 🔹 MAE (Mean Absolute Error)
- 🔹 MSE (Mean Squared Error)
- 🔹 RMSE (Root Mean Squared Error)
- 🔹 R² Score

### 🧹 Data Preprocessing
- 🔹 Handling Missing Values
- 🔹 Feature Selection
- 🔹 Data Cleaning
- 🔹 Data Transformation
